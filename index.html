游戏说明

操作说明

WS / ↑↓ 前进与后退。2D 模式使用 AD / ←→ 转向；3D 模式使用 AD / ←→ 横移，鼠标控制水平视角。

Q 发射红波，E 发射绿波，R 发射蓝波。Esc 暂停游戏。

游戏规则

视觉模块已经离线。利用声波探测墙体，穿过迷宫并抵达右下方的绿色能源补给站。

声呐波无法穿过墙体。红波不反弹；绿波最多反弹 3 次；蓝波进行 360° 环扫。补给站、能源晶体与道具持续辐射电磁信号，可穿墙被导航模块接收。移动时不消耗能源，但移动期间不会自然恢复能源；能源耗尽后仍可低速移动。

红波：2D 永久显影，3D 显影 9 秒。绿波：2D 显影 3 秒，3D 显影 7 秒。蓝波：2D 显影 7 秒，3D 显影 5 秒。

道具设定

回声信标：触碰后部署，始终显影更大范围内的迷宫墙壁。

静默电容：持续 8 秒；移动时也能恢复能源，但期间不能发射声波。

闪域谐振器：2D 下让所有墙壁连续闪烁 3 次；3D 下闪烁通往终点的路径 3 次。

所有道具均持续辐射电磁波，因此即使未被声呐扫描、或隔着墙体，也能被导航模块看见。绿色能源晶体同样可见并能恢复能源；道具和能源的位置由地图种子决定。

通关评级

B：70～100 秒　C：100～200 秒

关于

一款用声波代替视觉的迷宫导航实验。视觉模块离线之后，你只能听见世界，再一点点把它画出来。

作者

The_Symbol 符号符号男

独立开发者。负责玩法设计、程序实现、终端风 UI、声呐与回放系统。 若你在黑暗里听见回声——那大概就是他想让你听见的东西。

版本

26w30a SNAPSHOT · 2026 年第 30 周实验构建

版本号采用「年份缩写 + 周次 + 阶段」标记（如 26w30a）。本构建包含自定义终端滚动条、本地加密回放 / PK、标题 BGM 与工业风设置界面等近期改动。

技术框架

纯前端、零构建管线：原生 HTML / CSS / ES Modules，主循环驱动 Canvas 2D 渲染；3D 视角使用 Web Worker 做射线投射以减轻主线程负担。

音频为 HTMLAudioElement 流式 BGM；回放经 Web Crypto (AES-GCM) 加密后写入 localStorage。触摸摇杆与横屏引导面向移动端浏览器。

单元与浏览器集成测试由 Node.js 内置测试运行器驱动，无外部 UI 框架、无打包器。

协议与档案

核心循环：种子迷宫生成 → 声呐显影 → 能源管理 → 终点补给。本地最多保留 100 条加密回放，可导出分享串或生成竞速幽灵。

显示模式（2D / 3D）在开局锁定；手机端支持虚拟摇杆与滑动视角。设置中的 CRT、辉光、灵敏度与音量会保存在本机。
