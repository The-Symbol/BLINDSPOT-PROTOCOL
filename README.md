# 盲区协议 · Blindspot Protocol

**版本：** `26w30a`（2026 年第 30 周实验构建）  
**作者：** The_Symbol（符号符号男）

一款用声波代替视觉的迷宫导航实验。视觉模块离线后，墙体只有在声呐命中时才会显影；补给站、能源晶体与道具持续辐射可穿墙的电磁信号。地图、资源和道具位置由种子确定，相同种子会生成完全相同的迷宫与布局。

纯前端、零构建管线：原生 **HTML / CSS / ES Modules**，**Canvas 2D** 主循环渲染；3D 视角用 **Web Worker** 做射线投射。BGM 为 **HTMLAudioElement** 流式播放；本地回放经 **Web Crypto (AES-GCM)** 加密后写入 **localStorage**。

## 功能概览

- **2D 俯视 / 3D 第一人称**（开局锁定，局内不可切换）
- **三种声呐**：红波直射、绿波反射、蓝波 360° 环扫
- **种子迷宫**、能源晶体与道具布局可复现
- **本地加密回放**（最多 100 条）：观看、导出到 [pastes.dev](https://pastes.dev) 分享链接、从链接导入、与幽灵 **PK**
- **设置**：灵敏度、FOV、CRT、辉光、音乐/音效音量（本机持久化）
- **移动端**：虚拟摇杆、滑动视角、横屏引导
- **终端风 UI**：工业风滑块与自定义滚动条（桌面 + 触屏可拖）
- **BGM**：标题 / 探索 / 竞速 三轨，带淡入淡出

主菜单提供：唤醒机体、回放与 PK、游戏说明、设置、关于。

## 运行

页面使用 ES Modules，不能直接用 `file://` 双击打开。在项目目录启动任意静态服务器，例如：

```powershell
npx serve .
```

然后打开命令输出的本地地址。

## 操作

| 按键 | 作用 |
|------|------|
| `W` / `S` 或 `↑` / `↓` | 前进、后退 |
| `A` / `D` 或 `←` / `→`（2D） | 转向 |
| `A` / `D` 或 `←` / `→`（3D） | 横移 |
| 鼠标（3D） | 水平与俯仰视角 |
| `Q` | 红波（短冷却） |
| `E` | 绿波（中冷却，可反弹） |
| `R` | 蓝波（消耗能源，环扫） |
| `Esc` | 暂停（切后台也会自动暂停） |

移动端：虚拟摇杆移动，屏幕滑动控制视角；无法自动横屏时可手动旋转后继续。更完整的规则与道具说明见游戏内「游戏说明」。

## 评级

| 等级 | 通关用时 |
|------|----------|
| S | ≤ 50 秒 |
| A | 50～70 秒 |
| B | 70～100 秒 |
| C | 100～200 秒 |
| D | 超时失败（200 秒） |

## 检查与测试

需要 **Node.js 18+**：

```powershell
npm test
npm run check
```

`npm run check` 会对主要模块做语法检查，并运行全部单元 / 浏览器集成测试，覆盖包括：

- 地图与资源的种子确定性、起终点连通性
- DDA 网格射线、碰撞与墙角法线
- 对角移动与贴墙滑动
- 声呐冷却、蓝波能耗、绿波显影与反弹
- 计时器启动条件
- 回放采样、插值、加密分享串、pastes.dev 上传/链接导入、路径物理校验（防穿墙 / 超速 / 伪造通关）
- 本地存储容错
- 移动端横屏与触控视角

## 技术说明

- **无打包器、无 UI 框架**；模块直接由浏览器加载。
- Canvas backing store 最高约 `2×` DPR，兼顾清晰度与移动端性能。
- 3D 墙体与声呐碰撞使用网格 DDA，避免全墙线性扫描。
- 菜单 / 暂停 / 后台会降低模拟与绘制帧率，减轻空闲占用。
- 回放路径校验对贴墙滑动做了容差，合法局内操作不应误判穿墙；超速与明显穿墙仍会拒绝保存。
- 导出回放会将 `BSP1.` 加密串 `POST` 到 `https://api.pastes.dev/post`（[lucko/paste API](https://github.com/lucko/paste/blob/master/API.md)），并复制 `https://pastes.dev/{key}`；导入时对链接执行 `GET https://api.pastes.dev/{key}` 拉取密文。仍支持直接粘贴 `BSP1.` 串；也兼容旧的 `paste.lucko.me` 链接解析。上传失败时回退为复制加密串本身。
- `prefers-reduced-motion` 会关闭 CRT 刷新、闪烁与标题故障动画。
- 字体与 BGM 随项目本地交付；分享链接依赖外网 pastes.dev（仅在用户点击导出/导入时请求）。
